# EMSC2010 – Week 2 Practical 1: Working with GitHub and Colab

This repository contains the template Jupyter notebook for **Week 2 Practical 1** of *EMSC2010: Data Science for Earth System Scientists* at the Australian National University.

This is session introduces the **GitHub / Google Colab workflow** that will be used to access, edit, and save notebooks for the remainder of the course.

---

## Notebook

### Notebook 1 – Working with GitHub and Colab (`NB1`)

This notebook is a hands-on, first introduction to the course workflow. Students open the notebook in Google Colab, save a working copy to their Google Drive, perform a small test calculation in a code cell, and then commit the updated notebook back to their GitHub repository — establishing the round trip between GitHub, Colab, and Google Drive that will be used throughout the course.

**Key concepts:** Opening notebooks in Colab from GitHub, saving copies to Google Drive, editing and running code cells, committing changes back to GitHub

**Libraries:** None — this notebook contains no analysis code

---

## Getting Started

This is a **template repository**. To begin working on the notebook:

1. Click **"Use this template"** at the top of this page to create a copy of the repository in your own GitHub account.
2. Open the notebook from your copy of the repository and click the **"Open in Colab"** badge at the top of the notebook to launch it in Google Colab.
3. Before submitting, replace the `uXXXXXXX` placeholder in the filename with your ANU student UID.
4. Follow the in-notebook instructions to save a copy to Google Drive, make a small edit, and commit the result back to your GitHub repository.
